Wellness Score

A simple snapshot of your recent wellness habits.

0 – 100 Index

A deterministic, transparent score built on 5 weighted behavioral dimensions: Activity (25%), Hydration (20%), Sleep (20%), Daily Tasks (20%), and 7-day Logging Consistency (15%). It reflects daily lifestyle momentum and habit consistency rather than clinical pathology.

What it means
A holistic reflection of consistent daily habits, movement, hydration balance, and rest routines.
What it is not
Not a clinical pathology metric, lab value indicator, or medical diagnostic diagnosis.

Safety & Personalization

Your guidance is filtered through the information available to Vitalis.

Constraint Layer

Before any exercise or meal recommendation reaches you, it passes through strict safety constraint filters. If your profile notes knee sensitivity, high-impact jump routines are excluded. If you list allergies (e.g. peanuts or dairy), meal plans automatically eliminate contraindicated ingredients.

✓ Enforces biometric upper/lower boundaries on daily caloric and exertion advice.
✓ Eliminates allergen-containing food items at the inference filter stage.
✓ Swaps high-impact activity options for low-impact alternatives when joint limitations exist.

Reliability Engineering

Designed to fail safely

If an advanced recommendation path is unavailable or cannot confidently produce guidance, Vitalis can fall back to simpler validated logic rather than presenting unreliable output.

By prioritizing deterministic constraint safety over unverified predictions, the system preserves trust and continuous availability at all times.

1 Primary Path — Active Production ML Model
↓ If unavailable or out-of-distribution
2 Automated Rollback to Prior Validated ML Release Candidate
↓ If degraded runtime environment
3 Deterministic Rule-Based Engine (Constraint-driven inference)
↓ Cold start baseline
4 Safe Generic Baseline Guidance

Machine Learning Pipelines

Our recommendation architecture utilizes a validated gradient boosting pipeline trained on structured lifestyle cohorts. Unsupervised Isolation Forest algorithms monitor multi-dimensional activity vectors for outlier detection.

Explainability & Auditability

Every inference execution logs its input feature vectors, active model artifact hash, and confidence calibration scores to maintain complete algorithmic auditability.

Four-Tier Fallback Hierarchy

To guarantee high availability, Vitalis AI implements automated fault tolerance:

  • L1 Active Production ML Model
  • L2 Automated Rollback to Prior Validated ML Release Candidate
  • L3 Deterministic Rule-Based Engine (Constraint-driven inference)
  • L4 Safe Generic Baseline Guidance

Health & Clinical Disclaimer
